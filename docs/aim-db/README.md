# aim の記録の控え

⚠ **ここは手で直さない。** 正本は非公開の Artifact の DB であり、この dir はそこから作り直す写しである（人間の決定 2026-10-28）。

**何が在るか** —— `docs/aims/` の node を、**人間が決めたこと**と**エージェントの解釈**に分けた記録である。

| file | 1 行 = |
| :-- | :-- |
| `nodes.jsonl` | 1 つの aim（目的・親・状態・主に属する機能） |
| `features.jsonl` | 1 つの機能。4 つの固定の枠（全体・作る・記録する・出力する）の下に置く。一覧は人間が確定した |
| `categories.jsonl` | 1 つの話題の分類（エージェントが付ける補助のタグ） |
| `decisions.jsonl` | 人間の決定 1 件。`form` が `verbatim` なら `quote` は人間の言葉そのもの、`paraphrase` ならエージェントの要約、`pinned` なら目的として固定された `aim:` の文 |
| `interpretations.jsonl` | エージェントの解釈 1 件。`basis` が依って立つ決定を名指す。⚠ **空なら、それはエージェント自身の選択である** |

🔴 **決定は追記だけの記録である。** ∴ 書き出しは件数が減ると拒む（`scripts/aim-db-export.mjs`）—— 減るのは読み出しの途中切れか DB 側の喪失であり、黙って上書きすれば消えたことが差分に埋もれる。

**作り直し方** —— エージェントが `ArtifactData` の `list` に `out_dir` を付けて 5 つの collection を読み出し、

```
node scripts/aim-db-export.mjs <読み出した dir>
```

# aim の記録

🔴 **ここが aim の記録の正本である**（人間の決定 2026-10-29、`decisions.jsonl` の `bearing-x02`）。作業機（WSL）の hub が作業窓へ仕事を渡す形では、記録が git に在り、作業窓のセッション開始時に hook が読めることが前提になる。

⚠ **2026-10-28 の試作では、正本を非公開の Artifact の DB に置き、ここはその写しとしていた。** 10-29 に向きを反転した ∴ **Artifact のページは、ここから作る人間向けの面である**（ただし repo から DB へ流す道具はまだ無い。下の「道具」を見よ）。

**何が在るか** —— `docs/aims/` の node を、**人間が決めたこと**と**エージェントの解釈**に分けた記録である。

| file | 1 行 = |
| :-- | :-- |
| `nodes.jsonl` | 1 つの aim（目的・親・状態・主に属する機能） |
| `features.jsonl` | 1 つの機能。4 つの固定の枠（全体・作る・記録する・出力する）の下に置く。一覧は人間が確定した |
| `categories.jsonl` | 1 つの話題の分類（エージェントが付ける補助のタグ） |
| `decisions.jsonl` | 人間の決定 1 件。`form` が `verbatim` なら `quote` は人間の言葉そのもの、`paraphrase` ならエージェントの要約、`pinned` なら目的として固定された `aim:` の文 |
| `interpretations.jsonl` | エージェントの解釈 1 件。`basis` が依って立つ決定を名指す。⚠ **空なら、それはエージェント自身の選択である** |

🔴 **決定は追記だけの記録である。** 書き換えも削除もしない —— 誤りは、それを正す決定を足して示す。

**道具** —— `scripts/aim-db-export.mjs` は **DB → repo** の向きの道具である（試作の時の向き）。件数が減る書き出しは拒む。⚠ **正本が repo になった今、これを走らせると repo の追記を DB の古い内容で上書きしうる** —— 走らせる前に、DB が repo より新しいことを確かめること。⚠ **repo → DB の向き（ページを最新にする）の道具はまだ無い。**

⚠ **2026-10-29 の時点で、`docs/aims/` の本文はまだ並存している** —— どちらをどう退かせるかは決まっていない。

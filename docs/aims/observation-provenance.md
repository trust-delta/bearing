# IS

**調べるという行為そのものが、その事実が我々の外に在ることの証拠である。** ⚠ **我々が決めたことは、調べる必要がない** —— license を MIT にしたのも、供給を user スコープ 1 本へ寄せたのも、人間が決めた瞬間に真になり、我々が変えるまで真であり続ける。対して harness の振る舞い・API の形・道具の出力は、**我々が決められないから調べる**。∴ **調査と実測が扱うのは、はじめから借り物の真理である。**

**借り物ゆえに寿命が違う。** 決定は我々が変えるまで真、法（決定からの導出）はほぼ恒久。だが実測は**向こうが変えた瞬間に偽になり、通知は来ない**。⚠ **そして我々の機構はそれを検知しない** —— [[purpose-drift]] の fence が見るのは git 履歴の中の `docs/aims/` だけであり、**外部の系が動いたことは原理的に映らない**。∴ 現在形で書かれた実測は、踏むまで分からない地雷になる。

⚠ **だが地雷は実測そのものではなく、時制に局在している。** 「2026-09-04 に測ったら X だった」は、X が明日変わっても**真のままである** —— 過去形の観測は決して偽にならない。偽になりうるのは「X である」という日付の無い断定だけ。∴ **捨てる必要は無く、書き方を変えれば同じ内容が地雷から裏書きへ変わる。**

**手段は 3 つで、どれも安い。** ⑴ **時制と日付** —— 実測は「いつ・何を・どう観測したか」の形で書き、現在形の断定へ畳まない。⑵ **確信の階級を字面に出す** —— 「（実測 YYYY-MM-DD、対象: <系>）」「（人間の決定 YYYY-MM-DD）」「（docs の読みであって実測ではない）」。⚠ **読み手が「誰が真にしている事実か」を字面から読み取れなければ、地雷は地雷に見えない。** ⑶ **再測できるなら、その 1 行を添える** —— 5 秒で確かめ直せる観測は、地雷ではなくセンサーである。⚠ **再測できないものは、そう明示する**（「人間が 3 つのセッションから面が消えるのを見た」は再現できない）。

⚠ **置き場は `CLAUDE.md` の marker の外である**（人間の決定 2026-09-04）。`/bearing:with-aim` が置く block は **aim についてだけ**を持つべきであり、**この法は aim に限らない** —— baton・PR・commit message・code コメント・doc、**記録として残るものすべてに効く** ∴ block の中には入らない。⚠ **そして block の外は生成で復元できない** ∴ 同じ日に `CLAUDE.md` を tracked にした（[[bearing]]）。

**この法が要ると分かったのは、木が大きくなったからではなく、大きな木が実際に誤らせたからである**（実測 2026-09-04、1 セッション）。エージェントは `bearing.md` を端から端まで読んだうえで、⑴ **既に 18 行目に書かれている事実を「木にまだ無い穴」として報告し**、⑵ **正しかった過去の観測を「誤読だった」と訂正しようとした**。どちらも人間が捕まえた。⚠ **大きな corpus の失敗様式は「見つけられない」ではなく、「読んだという確信が得られてしまう」ことである** ∴ 量は人間の校正負荷へ転嫁される —— **守るはずだった資源そのものが減る。**

⚠ **量そのものへの対処は保留されている**（人間の決定 2026-09-04）。実測を aim node から分離する置き場（boot で読まれない層）を作る案は在るが、**採るのは「さらに膨れたら」の合図が出てからである** —— **先に述べ方が直れば、膨らみ方そのものが変わりうる** ∴ 置き場を先に作れば、直っていない書き方のまま移設するだけになる。

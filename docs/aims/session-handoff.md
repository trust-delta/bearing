# IS

**圧縮との差は「選んだかどうか」である。** ネイティブ圧縮は反応的で不可視であり、落ちたものを誰も選んでいない。⚠ **本 node の価値は baton の構造ではなく authoring の judgment にある** —— 何を残し何を「git と目的から再導出できる」として捨てるか、その判断こそ圧縮に欠けているものだ ∴ **機械が触ってよいのは判断でない部分だけ**（退避・刻印・機械的な差分）で、取捨には一切触れない。

**発火点は圧縮の直前である。** ⚠ **hook から使用率メーターを見る術は無い**（どの hook event の入力にも context の欄が無い）が、ハーネスは圧縮を決めた瞬間にそれを告げる。⚠ **これは閾値の代用ではなく閾値そのもの**で、しかも [[bearing]] の言う「置き換えない」に適う —— 圧縮を禁じるのではなく、**沈黙の破棄を 1 度だけ差し止めて選択を人へ返す**。

⚠ **baton が痕跡を残さないことは、この node の外にも効いている** —— [[supply-scope]] は「痕跡を残さない機能は user 単位で有効になる」の側に handoff を置く ∴ **baton が消費者の repo で tracked になりうる状態は、あちらの `[todo]` として立っている。**

⚠ **数字が見えても発火点は動かない。** [[ambient-display]] は statusline の側から `context_window.used_percentage` を受け取れる —— **hook に無いものが、あちらには在る**。だがそれは人間が読む数字であって機構の起点ではない: statusline は hook ではなく、何も起動できない。∴ あの面が増やすのは**人間が自ら handoff を選ぶ機会**であり、この node の閾値を置き換えはしない。

⚠ **人が自ら圧縮を指示したときは決して差し止めない。** 人の act を、その人のための儀式で上書きするのは体制の反転である。

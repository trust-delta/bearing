# IS

**分割は所有で引く。** 目的（`aim:` 1 文）は人間のもので、エージェントは書き換えない。手段（body）はエージェントのもので、人間は妥当性を確認する。⚠ **この非対称が機構の全てである** —— 目的まで書けるエージェントは、達成できない目的を達成できる形に書き直せてしまい、そのとき失われたことは誰にも見えない。

**置き場はリポジトリである。** 目的は git artifact として commit され、vendor の memory にも会話にも住まない ∴ 機械が変わっても vendor が変わっても目的は残る。これは [[session-handoff]] が時間方向で担うことの、空間方向の対応物である。

**木で構造化する。** 1 目的 1 ファイル、親が目的、子が小目的。⚠ **body の中に階層を作り始めたら、それは子 aim が隠れている合図**であって、見出しを足す合図ではない。

⚠ **実装は前身から運ぶが、正当化は運ばない。** コードは動く実体として持ってくる。だがそれが *外付け拡張として* 妥当かは、ここで実際に使いながら書き直す。
